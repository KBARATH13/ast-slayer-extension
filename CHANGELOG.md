# Changelog

All notable changes to **AST Slayer** will be documented here.

## [1.0.0] - 2026-11-15
### Added
- **Zero-Config Background Engine:** Automatic document interception on file open and save without needing external MCP configuration.
- **Live Status Bar Telemetry:** Added bottom-right token counter with a dynamic spinning animation during active file calculation and a Neon Emerald (`#00E676`) idle indicator.
- **Detailed Output Channel:** Added ISO-timestamped per-file reduction logs (`raw → optimized tokens`) under the `AST Slayer` output channel.
- **Explorer File Decorations:** Added green `⚡` badges for supported code files (`.ts`, `.tsx`, `.js`, `.dart`, `.sol`).
